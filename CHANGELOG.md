- **Build Workshop**: 3-day workshop application and information pages
- **Design Partner Program**: Partnership application and details
- **Done For You Service**: Full-service application with countdown timer
- **Funnel Support**: Concierge support packages
- **Funnels**: Sales funnel packages and application system

- **Simple Websites**: Portfolio showcase and application system
- **Thank You Page**: Post-purchase confirmation with segmentation
- **Vault**: Resource library with lifetime access
- **Viral Course**: Course offering with module breakdown
- **Workshop**: Branding workshop with 3-day plan
